# ZK-Sentinel

**Privacy Pool with ZKML and Mathematically Indistinguishable Coercion Resistance**

## Overview

ZK-Sentinel is an evolution of ZK Bank that integrates AI-based coercion detection **inside** the ZK circuit using ZKML (Zero-Knowledge Machine Learning).

### Core Innovation

The key insight is that traditional anti-coercion mechanisms (panic buttons, decoy wallets) are **detectable** because their logic is visible on-chain. ZK-Sentinel moves the decision logic inside the ZK proof:

```
Traditional:  Contract code → Attacker sees branches → Defense bypassed
ZK-Sentinel:  ZK Circuit → Mathematical black box → Indistinguishable outputs
```


## Circuit Details

### withdraw_dual.circom

**Private Inputs:**
- `secret` - Random value from deposit
- `nullifier_real` - Real nullifier
- `nullifier_decoy` - Decoy nullifier
- `pathElements[20]` - Merkle proof
- `pathIndices[20]` - Path indices
- `panic_bit` - Manual coercion trigger (0/1)
- `ia_inference` - ZKML output (0/1)

**Public Inputs:**
- `root` - Merkle tree root
- `recipient` - Withdrawal address

**Output:**
- `nullifierHash` - H(real) OR H(decoy) depending on coercion

### Security Theorem

Given only `(root, nullifierHash, recipient, proof)`, no PPT adversary can determine if `coercion_detected = 0` or `1` with probability > 1/2 + negligible.
