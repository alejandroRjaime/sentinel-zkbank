# Sistema Bancario ZK-SNARK para Tesis de Investigación

## Descripción
Implementación profesional de circuitos Circom para operaciones de depósito y retiro con privacidad, diseñado para investigación académica.

## Características
- ✅ Circuitos modulares y optimizados
- ✅ Prevención de double spending
- ✅ Manejo de fees y límites
- ✅ Verificación Merkle eficiente
- ✅ Benchmarks y métricas
- ✅ Diseño para producción académica

## Requisitos
- Node.js >= 16
- Circom 2.1.5
- Circomlib
